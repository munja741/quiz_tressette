# Otvorena pitanja

Tvrdnje o hrvatskoj praksi koje još nisu potvrđene. U lekcijama su označene komentarom `TREBA POTVRDITI`.

| Lekcija | Pitanje |
| --- | --- |
| `pravila` | Tko dijeli prvi u partiji uživo? |
| `punti-i-bele` | Kako se kod nas zove dosta i kako se kažnjava pogrešno zvanje? |
| `signali` | Daju li se bato i strišo gestom ili riječju? |
| `bonton` | Što se za stolom smije reći, kako se rješavaju sporovi i koje su kazne, osim lažne akuže i nedopuštenih znakova. |
